# R5 · Content Editor (phase spec)

_Status: scoped · Free (on device) · iPad and Mac only for code editing · Depends on: R1.5 (EPUBCore)_

## Goal
Calibre's "Edit book" features, reimplemented: edit what's inside an EPUB.

## Scope
1. **File browser** of the EPUB's contents (text, styles, images, fonts, OPF, navigation); add, rename, delete, reorder spine items.
2. **Code editor** for XHTML, CSS, OPF and NCX with syntax highlighting and error markers (candidate: Runestone, MIT; Lead confirms).
3. **Live preview** (WKWebView) beside the editor, synced to the cursor position.
4. **Table of contents editor:** generate from headings, edit tree, write both EPUB 3 `nav.xhtml` and EPUB 2 `toc.ncx`.
5. **Find and replace** across files, with regex, saved searches and preview of changes.
6. **Book checker:** our own rule set modelled on common EPUB validation categories (container, OPF, manifest/spine consistency, broken links, missing files, invalid XHTML, missing alt text). epubcheck (Java) cannot run on iOS; on Mac, optional use of a user-installed epubcheck may be evaluated.
7. **Tools:** remove unused CSS, compress images, embed or subset fonts, smarten punctuation.
8. **Devices:** code editing on **iPad and Mac only**. iPhone gets the book checker and metadata editing, not the code editor.

## Acceptance criteria
- Editing and saving any fixture EPUB keeps it valid per the book checker and readable in Apple Books.
- Book checker finds all seeded errors in a fixture set of 30 broken EPUBs, with no false errors on 20 valid ones.
- Regex replace across 500 files previews and applies in under 5 s on an M-series Mac, with undo.
- External pen test before release.
