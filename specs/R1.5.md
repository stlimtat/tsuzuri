# R1.5 · Metadata Editor Lite (phase spec)

_Status: scoped · Free (on device) · Depends on: R1 (Library, Persistence, App Shell)_

## Goal
Fix book metadata for Apple Books: open an EPUB, edit the basics, save it, and send it back to Books. This also builds the EPUB core that R2–R5 reuse.

## Scope
1. **EPUB core package (`EPUBCore`, Tier 1):** open and save EPUB 2 and 3 with our own code (no Calibre, no GPL). ZIP via a permissive library (e.g. ZIPFoundation, MIT). On save, `mimetype` is the first entry, stored uncompressed. XML via a libxml2 wrapper; unknown OPF elements and attributes are preserved byte-for-byte where untouched.
2. **Books in the Library:** importing an EPUB creates a Work with `kind = .book`.
3. **Edit:** title, sort title, authors (with "file-as"), series and series number, cover image.
   - Series written both as EPUB 3 `belongs-to-collection` (`collection-type=series`, `group-position`) and as `calibre:series` / `calibre:series_index` meta tags, for broad reader support.
   - Cover updated in both the EPUB 3 `cover-image` manifest property and the EPUB 2 `<meta name="cover">`.
4. **Send to Books:** share sheet "Open in Books", with a one-screen guide: Apple doesn't let apps change the Books library, so Books adds a new copy; delete the old copy in Books; collections and reading position may not carry over.
5. **DRM:** DRM-protected EPUBs (e.g. Books Store purchases) are detected and refused with an explanation.
6. **Mac experiment (internal testing only, not shipped):** a debug-only tool that tests editing books inside the Mac Books library's files, to learn whether Books picks up changes. Results recorded; no user-facing feature unless the Lead decides otherwise with a new ADR.

## Acceptance criteria
- Round trip: open → save without edits yields an EPUB that passes the R5 book checker and opens in Apple Books, with the OPF semantically unchanged.
- Edited title, author, series and cover appear in Apple Books after "Open in Books" (manual test on iPhone, iPad and Mac).
- Fixture set: 20 EPUBs (EPUB 2, EPUB 3, fixed layout, Japanese vertical writing, odd OPF structures) round-trip without loss.
- DRM fixtures are refused.
- External pen test before release (importer fuzzing focus).
