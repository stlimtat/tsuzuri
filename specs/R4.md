# R4 · Conversion (phase spec)

_Status: scoped · Free (on device) · Depends on: R1.5 (EPUBCore), R3 (metadata)_

## Goal
Convert the user's other files into clean EPUBs, preserving images, with our own converters (no Calibre code, no GPL/LGPL libraries).

## Formats, in priority order
1. **CBZ / CBR / image folders → fixed-layout EPUB 3** (one Page per spread item, right-to-left page progression for manga).
2. **DOCX → EPUB:** headings to table of contents, styles to CSS, images, footnotes, tables.
3. **TXT / HTML / Markdown → EPUB:** chapter detection by heading or pattern; encoding detection (UTF-8, Shift_JIS, others).
4. **Text-based PDF → EPUB:** PDFKit text extraction with reflow heuristics (headers/footers removed, paragraphs joined), images extracted. **Scanned PDFs are out of scope.**
5. **FB2 → EPUB:** XML mapping including embedded images and metadata.
6. **DRM-free MOBI / AZW3 → EPUB:** our own parser for PalmDOC/KF8; DRM-protected files are refused.

## Requirements
- All conversion on device; large files in the background with progress.
- Metadata carried over and editable (R3) before saving.
- Output passes the R5 book checker.
- Importers are hardened like R1's archive import (size limits, fuzzing).

## Acceptance criteria
- Fixture set per format converts with images preserved and a navigable table of contents.
- Converted EPUBs open in Apple Books and pass the book checker with no errors.
- Fuzzing of every parser for 24 h without crashes.
- External pen test before release.
